# Tasks

## 1. Preizkus na PS4

- [ ] 1.1 Uporabnik odpre igro v brskalniku PS4 in preveri nalaganje in prikaz čez cel zaslon televizorja (brez drsnikov, ostra slika); nalogo označi šele po potrditvi uporabnika
- [ ] 1.2 Uporabnik preigra prvo sobo s tipkovnico (puščice, Y skok, X kepa): gibanje, lestve, prepad, konice, kepe, živali, točke, cilj in utrujenost; nalogo označi šele po potrditvi uporabnika
- [ ] 1.3 Uporabnik preigra prvo sobo s kontrolerjem PS4 (križec ali leva palčka, × skok, □ kepa); nalogo označi šele po potrditvi uporabnika
- [ ] 1.4 Napake, ki jih preizkus odkrije, se popravijo (ali prenesejo v novo spremembo) in preverijo z `npm run lint`, `npm test` in ponovnim preizkusom na PS4; če napak ni, se naloga označi ob potrditvi 1.1–1.3
